# 线圈路径拐角缺陷与修正报告

日期：2026-09-19
范围：`C:\wpt\coil_gen.py` 的路径参数化（径向重映射）
状态：**已定位、已修正、已离线验证；A/B 实测见第 8 章**
触发：用户在 AEDT 窗口目视发现"模型的拐弯处不对"

---

## 1. 摘要

参数化线圈生成器 `coil_gen.make_path()` 用「逐点切比雪夫半径」做径向重映射，
在偏离参考参数时会把**拐角圆角挤成尖刺**：

| | 旧口径（legacy） | 修正口径（ring） |
|---|---|---|
| 最大转角（中位 / 最坏） | 37.44° / **98.70°** | **11.46° / 11.68°** |
| 转角 >15° 的工况 | **214 / 256** | **0 / 256** |
| 参考点恒等性 | — | 1.18e-5 mm（数值级）✓ |
| 直边匝间最小净间隙 | 0.680 mm | **0.680 mm（完全一致）** |
| 直边环半径 vs 口径公式 | — | **0.00000 mm** |
| 外缘锚点（= LC·K_LC/2） | — | **0.0000 mm** |

本批 256 个工况中 **214 个（84%）几何受影响**，铜带走线在拐角处最大位移 ~3.6mm，
且位移量**随 (LC, KR) 系统性变化** —— 属于会污染代理模型的那类工况相关偏差。
同会话 A/B 实测：**电感差 0.7~1.5%**（L33 +1.50%、M13 +1.01%、L11 +0.87%）。

修正还**治愈了一个求解失败**：旧几何下 `b1_0163` 在扫描端点 x=S/2 无法求解
（`AnalyzeAll` 报错），修正后同一位置 6.73 分钟正常解出。

修正只改重映射坐标（`s` → 环半径 `R`），**参考参数下逐点恒等**，因此历史所有
以参考点为基准的验证结论不受影响。

---

## 2. 现象

用户在 AEDT 窗口观察到线圈拐角形状异常。肉眼可见的是"圆角变成折角/尖刺"。

先排除的两个可能：

| 假设 | 检验 | 结论 |
|---|---|---|
| 拐角处匝间被夹紧（间隙变小） | 逐点算 i↔i+64 的欧氏距离，与径向间隙对比 | **排除**：径向 5.104 vs 欧氏 5.104，差 0.000mm |
| 圆角离散刻面太粗 | 8 弦/90° 的刻面偏差 | **排除**：参考点仅 0.146mm，不构成视觉异常 |

再查**段间转角**，异常立刻显现：

| 工况 | 最大转角 | >20° 段数 |
|---|---|---|
| 参考点 LC=165 / KR=0.3587 | 11.46° | 0 |
| **屏幕上那个 LC=216.77 / KR=0.2294** | **76.26°** | **79** |
| 本批 KR≈0.20 档（最坏 b1_0169） | **98.70°** | 19 段 >40° |

11.25° 是模板固有的圆角离散角（8 弦拟合 90°），参考点 11.46° 与之吻合；
76~99° 则是**假尖角**。

---

## 3. 根因

`make_path()` 旧实现：

```python
s  = max(|x|, |y|)                       # 逐点切比雪夫半径
k  = (h_out' - h_in') / (h_out_ref - h_in_ref)
f  = [h_in' + (s - h_in_ref)·k] / s      # 逐点缩放系数
p' = 模板点 × f
```

问题在于 **`s` 并不是"环半径"**：

- 直边上 `s = max(|x|,|y|) = R`（环半径）✓ 成立
- **圆角上 `s` 会掉到 R 以下**（圆角切掉了角）：模板第 1 匝实测
  `s ∈ [26.45, 34.14]`，而该处环半径 R ≈ 30 → 圆角处 `s` 比环半径低 **3.55mm**

于是同一个圆角上各点拿到的 `f` 不同：

- 直边点的 σ（缩放系数）范围 0.7753 ~ 1.3138
- 圆角点的 σ 范围 0.7412 ~ 1.3026
- **同一匝内 σ 相差 68%**

圆角的**切向**尺寸按环半径缩小、**径向**尺寸按 `k` 放大 → 圆角被拉成径向尖刺。
`k` 与"切向/径向尺度比"偏离 1 越远，尖角越严重，所以 **KR 偏小（0.20 档）与偏大（0.50 档）
两头都坏**，只有 KR≈0.3587（模板原生参数）干净。

## 4. 影响面（全批 256 工况）

| 判据 | 工况数 |
|---|---|
| 转角 > 15°（模板固有值 11.25°） | **214 / 256 (84%)** |
| 转角 > 40° | **118 / 256 (46%)** |
| 转角 > 60° | **43 / 256 (17%)** |
| 干净（11.4~11.8°） | 仅 KR≈0.354~0.359 那几档 |

最大转角中位 37.44°、p90 75.74°、最坏 98.70°。
几何位移（修正前后）中位 1.29mm、p90 2.43mm、**最大 3.59mm**。

**为什么以前没发现**：参考点 LC=165 / KR=0.358674 恰好是模板的原生参数，
此时 `f ≡ 1`（逐点恒等）—— 文档里"参考参数下逐点恒等 / 纯缩放无失真"的结论
**只在该点成立**。历史验证（网格提速、4 弦模板、镜像半扫、多实例）全部在参考点或
其附近完成，因此这个缺陷从未暴露；而当时的 LC=120/200 等参数化试验虽然带着尖角，
但只做了"同几何 A/B"式的电感对比，几何本身没被审视。

## 5. 修正方案（迭代过程）

| 版本 | 做法 | 结果 |
|---|---|---|
| v1 | 用「s 的局部极大」估计环半径 | ✗ 间隙被破坏（1.676→0.719mm），位移 45mm |
| v2 | 相位映射但**叠加在已变形路径上** | ✗ 方法错误（应在原始模板上施加） |
| v3 | 相位映射（u = 累积转角/总转角）施加于模板 | ✓ 尖角 0/256，但环半径与线性假设偏差 ≤0.9mm |
| v4 | 模板环半径 + 仿射映射（局部极大估计） | ✓ 尖角 0/256，但匝间距不均匀度 0.54mm |
| **v5（采用）** | **环半径 + 仿射映射（圆角点用两端直边线性插值）** | ✓ **尖角 0/256、间距口径与 legacy 一致** |

**v5 实现**：

```python
# 1) 圆角点判定：段间转角 > 0.05°
# 2) 环半径 R = s（直边处精确成立）；圆角点的 s 用两端直边点的 s 线性插值替代
# 3) f = [h_in' + (R - h_in_ref)·k] / R ；p' = 模板点 × f
```

为什么 v5 同时满足两个要求：

- **直边**：`s = R` → `s' = h_in' + (R - h_in_ref)k`，匝间距严格等于 `(h_out'-h_in')/12`
  → 与 legacy 的间距口径**完全一致**（实测最小净间隙两者都是 0.680mm）
- **圆角**：`f` 沿圆角缓慢变化（跟随环半径的自然增长，跨越一个圆角仅 ~2%）
  → 圆角按环半径等比缩放，形状保持 → 无尖刺

## 8. A/B 实测（AEDT，同会话）

工况 `b1_0163`（LC=216.77 / KR=0.2294，旧几何最大转角 76.3°），同会话、同网格配置，只换线圈路径口径：

| 2 | ring | x=0 | ✓ L11=22.037 L22=22.141 L33=25.834 M12=-0.123 M13=-0.8010 M23=-0.7000 | 6.24 min |
| 3 | **ring** | **x=S/2** | **✓ L11=21.393 L22=22.577 L33=25.289 M12=-0.098 M13=-0.0070 M23=1.9150** | 6.73 min |

**① 修正对电感的影响（同位置 x=0，legacy → ring）**

| 量 | legacy | ring | 变化 |
|---|---|---|---|
| L11 | 21.848 | 22.037 | **+0.87%** |
| L22 | 21.960 | 22.141 | **+0.82%** |
| L33 | 25.453 | 25.834 | **+1.50%** |
| M12 | -0.122 | -0.123 | +0.82% |
| M13 | -0.793 | -0.801 | **+1.01%** |
| M23 | -0.695 | -0.700 | +0.72% |

线圈体积 6133.17 → 6160.47 mm³（+0.45%，尖刺把拐角路径缩短了）。
偏差量级 **0.7~1.5%**，与文档精心预算的网格开关偏差（0.25%）相比更大，且**随 (LC, KR) 变化**
—— 若带缺陷跑完 256 个工况，等于向代理模型注入 ~1.5% 的假参数效应。

**② 端点求解失败被治愈 ✓**

修正前：`b1_0163` 在 x=S/2（端点）`AnalyzeAll` 报错、1m35s 返回 `Status='Error'`，
同几何在 x=0 / S/4 / 0.85·S/2 均正常（5.8~6.8 min）——只有最端点失败。
修正后：同一位置 **6.73 min 正常解出**（M13=-0.007、M23=1.915，物理合理：
接收线圈此时几乎脱离 Tx1、正对 Tx2 外缘）。

结论：拐角尖刺导致扫掠体在端点位置网格病态，是端点失败的根因。

**③ 过程记录**：第 4 阶段（`b1_0169`）遇到 AEDT 会话中途退出
