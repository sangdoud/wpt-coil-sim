## 2. 几何口径

### 2.1 线圈尺寸（Lc 口径）

```
K_LC = 167.2829 / 165 = 1.013836          # 文档 Lc -> 实际中心线外跨
h_out = Lc × K_LC / 2                     # 最外匝中心线半跨
h_in  = r_h × Lc × K_LC / 2               # 最内匝中心线半跨
```
`coil_gen.make_path(LC, KR)` 的 `LC` 用**文档口径**，内部乘 `K_LC`。
本批**不**做任何额外换算：`coil_size` 直接传入。

### 2.2 路径重映射（2026-09-19 拐角修正，重要）

```python
PATH_MODE = "ring"        # 环境变量 WPT_PATH_MODE 可切 "legacy" 回滚
```
- 旧口径（legacy）用逐点切比雪夫半径 `s = max(|x|,|y|)` 做径向重映射，**在拐角圆角处
  把圆角挤成径向尖刺**：全批 256 工况中 214 个出现 >15° 假尖角，最坏 98.7°；
  同会话 A/B 实测对电感影响 **0.7~1.5%**，并导致扫描端点位置求解失败。
- 现口径（ring）以**环半径**为重映射坐标（直边 `s` 即环半径，圆角点的 `s` 用两端直边
  线性插值），修正后全批最大转角 ≤ **11.68°**（模板固有 8 弦离散角 11.25°），
  参考参数下与旧口径**逐点恒等**。
- 详见《拐角重映射缺陷与修正_20260919.md》。

**结论：本批几何是"均匀缩放的方螺旋 + 圆角等比"，不是文档历史参数化试验所用的带尖角几何。**

### 2.3 固定常量

| 常量 | 值 |
|---|---|
| 铜带宽 / 厚 | 2.0 / 0.5 mm |
| 匝数 | 12（模板 768 点 / 767 段） |
| 两层铜带间介质层 | 0.15 mm（Tx1 上层、Tx2 下层，沿 x 镜像不是彼此镜像） |
| 引线半径 | 0.3 mm |
| 接收平面 | z = 30 mm |
| 铁氧体开孔半径 | 1.0 mm（仅接收引线穿过） |

### 2.4 铁氧体（两侧独立）

```
tx_bar_w = 30 × tx_fill      rx_bar_w = 30 × rx_fill
ferrite_len = round(1.2 × Lc)                  # 两侧相同，取整 1mm
edge_gap    = round(g × Lc)                    # 发射边沿间隙（取整 1mm，负=重叠）
center_dist = Lc + edge_gap
单元节距 = 30 mm（条宽 + 条间气隙）
```
- Tx 条：z ∈ [−30 − tx_thick, −30]；Rx 条：z ∈ [60, 60 + rx_thick]
- 条长方向 Y 半长 = ferrite_len / 2
- **接收铁氧体随接收线圈一起平移**（与生产口径一致）

### 2.5 发射线圈摆位

`set_tx_gap(edge_gap, outer)`，`outer = Lc + 2`；Tx1 在 −x，Tx2 在 +x。

## 3. 扫描口径

```
全扫 41 点：x_i = −S/2 + i·S/40,  i = 0..40,  S = Lc(2+g)
半扫 21 点：x_i =      i·S/40,   i = 0..20       # ① 只算 x ≥ 0
镜像展开：M1(−x) = M2(+x),  M2(−x) = M1(+x)
```
- 本批 S 范围 184.8~528.6 mm，步长 4.62~13.22 mm
- 每个位置**逐点求解**（改接收位置后 0.05mm 往返强制网格失效）
- 曲线表 `M_pp` 列留空，由 `cases` 表的路径均值标量回退（契约 3.5）

## 4. 空气域（口径已固定，**与前文档不同，务必注意**）

```
Region 固定盒：X ±420.0 ／ Y [−134.94, 161.0] ／ Z [−45.0, 75.0]   （单位 mm）
```

**为什么不是文档的 X±330**：文档的 ±330 是按**旧生产扫描**（接收位移 ≤ ±150mm）定的；
契约口径的扫描跨度是 ±S/2（本批最大 ±264.3mm），加上接收线圈自身半宽后
**需要 X 半宽 ≥ 375.2mm**。实测（`b1_region_check.csv`）：

| 盒子 | 越界工况 | 越界点位 |
|---|---|---|
| X±330（文档值） | **21 / 256** | **45 / 5376（0.8%）** |
| X±420（本批采用） | 0 | 0 |

越界点全部落在**扫描端点**，而端点正是 `M_sum_var` 的来源，因此必须用装得下的固定盒。
留边 40mm（最外物体到盒面），与"区域不贴物体"的一贯口径一致。

**其他约束（不可改）**：−Y 面必须落在 y=−134.94（发射引线端子面）、+Z 面必须落在 z=75
（接收引线顶端面），否则 Maxwell 报 `Illegal external terminal`。

## 5. 求解设置

| 项 | 值 |
|---|---|
| 求解类型 | Maxwell 3D **Magnetostatic** |
| MaximumPasses / PercentError | 8 / 5% |
| PercentRefinement | **10**（BASE 回退时 5） |
| RelativeResidual | **1e-05**（BASE 回退时 1e-06） |
| UseIterativeSolver / SolveMatrixAtLast | true / true |
| 核数 | 8 |
| 激励 | Tx1 = Tx2 = 10 A，Rx = 0 A |
| 材料 | 铁氧体 μr = 1000、电导率 0；铜为默认 |
| 输出 | L 矩阵（3×3），`Lmatrix.L(Winding_i, Winding_j)` |

### 5.1 网格提速开关与闸门

```
FLEX_MESH = True        # 柔性网格（TAU Flex）
REGION_MAX_LEN_DIV = 5  # ⑥ Region 最大单元 = Lc/5
PCT_REFINEMENT = 10     # 原 5
RELATIVE_RESIDUAL = 1e-5  # 原 1e-6
```

## 6. 交付文件

### 6.1 `b1_cases.csv`（每工况一行，列名逐字对齐契约）

```
case_id, coil_size, hole_ratio, tx_fill, rx_fill, tx_thick, rx_thick, spacing_ratio,
tx_bar_w, rx_bar_w, ferrite_len, edge_gap, center_dist, sweep_span, n_points,
n_bars_rx, rx_volume, M_pp, raw_file
```
- `M_pp` = 原边两发射线圈互感（= `M12`）的**路径均值**口径，单位 μH
- `n_bars_rx` / `rx_volume` 用**实际铺设条数**回报（不是公式估计）
- `raw_file` 留空（可复算：见第 8 章）

### 6.2 `b1_curves.csv`（长表，每工况 41 行）

```
case_id, position_x, M1, M2, M_pp, L11, L22, L33, k13, k23
```
- `M1` = M13，`M2` = M23；`position_x` 单位 mm；电感单位 μH
- `M_pp` 列按契约留空（用 `cases` 的标量）
- `L11/L22/L33` 为逐点数值（随接收位置有 ~1% 波动，属正常）

### 6.3 `b1_selfcheck.csv`（独立自检表）

```
case_id, x0_M1, x0_M2, asym_pct, mirror_sum_pct, mirror_ind_pct, mirror_pairs,
mirror_pass, equidistant, k_ok, L_positive
```
- `asym_pct` = x=0 处 |M1−M2| 固有非对称度（参考点实测 2.19~2.23%）
- 后三列为本批新增的有效性标记

> ⚠ **`asym_pct` 的适用边界（2026-09-19 实测发现）**：契约口径 `asym_pct = |M1−M2| / max(|M1|,|M2|)`
> 是**相对量**，当 x=0 处两个互感都接近零时会爆炸。实测 `b1_0169`（g=+0.3464，发射线圈间隔 57mm，
> 接收线圈居中时磁通互相抵消）给出 **asym_pct = 143.7%**，但绝对差只有 **0.102 μH**；
> 按曲线峰值归一化则为 **1.60%**，与参考点 2.19~2.23% 同量级 ✓。
> 因此：**该列只在 x=0 处 |M| 足够大（线圈重叠较多、g 较小）时可比**。
> `b1_diag.csv` 另附 `asym_peak_pct`（峰值归一化口径），跨工况比较请用后者。

### 6.4 `b1_diag.csv`（额外诊断，**不属于契约**）

目标量（`M_sum_mean`、`M_sum_var`、`M_pp` 及极值）、自检结果、逐点耗时、
会话数、实际条数/条宽/条长/边距/跨度/体积、点位误差。

## 7. 精度与误差预算（本批配置）

| 来源 | 量级 | 说明 |
|---|---|---|
| ④ 8 实例并行 | **0.000%** | 实例间逐位一致（文档实测） |
| ① 镜像半扫 | 和口径 0.42%；个体 2.07% | 只影响导出的 `M1/M2/k` 列；四目标用的 `M_sum` 不受影响 |
| 网格开关组合（OPT vs BASE） | 同会话 ≤0.25%；跨工况 0.33~1.07% | 见 5.1 闸门 |
| 拐角几何修正 | **已消除**（旧口径曾带来 0.7~1.5% 参数相关偏差） | 本批用修正几何 |
| 空气域口径 | 固定盒，全批一致；与旧文档 ±330 不同 | 跨批次对比时须核对 |
| L33 固有噪声 | ~1.0%（L11 ~0.1%） | 与措施无关，建议放宽该列权重或重复取均值 |
| **目标量合计** | `M_sum` ~0.6%、`M_pp` ~0.25%、`V_rx` 0% | 四目标都在 0.5% 量级 |

**三条判读纪律**（沿用文档结论）：① 网格/几何带来的多为**系统性偏移**，对代理模型无害，
只影响与历史数据的绝对可比性；② 真正污染模型的工况相关波动约 0.3~0.7%；
③ L33 的 ~1% 噪声是精度瓶颈。

## 9. 与《技术文档 v2.0》的差异（逐条）

| # | 项 | 文档 v2.0 | 本批实际 | 原因 |
|---|---|---|---|---|
| 1 | 空气域 | 固定盒 X±330 / Y[−134.94,161] / Z[−45,75] | **X±420**（Y、Z 同） | ±330 按旧扫描跨度定；契约扫描端点需 ≥375.2mm |

| 6 | Sobol 抽样（文档建议） | 建议替换 LHS | 输入为给定 LHS 表 | 本批数据由软件端给定 |
| 7 | 求解失败快速退出 | 读 `.profile` Status | 保留，但实测该路径未触发（失败点仍会占用 25 分钟超时） | 已在 worker 增加 AEDT 消息抓取；建议后续改进 |

## 10. 已知限制

1. **修正几何与历史参数化数据不可直接混用**：旧参数化数据（LC=120/200 等试验）带拐角尖角，
   电感差 0.7~1.5%，且随参数变化。参考点（LC=165 / KR=0.358674）不受影响。
2. **`M1/M2/k13/k23` 的镜像半边带 ~2% 系统非对称**（① 的固有代价），`M_sum` 与 `M_pp` 不受影响。
3. **L33 噪声 ~1%**，单点值的有效位数受此限制。
4. **BASE 回退的 35 个工况**与前者的网格口径不同（见 5.1），跨工况比较时需知悉；
   `b1_diag.csv` 未单列该标记，可由 `coil_gen.path_dims(Lc, r_h)['gap_min'] < 1.5` 判定。
5. 中途发生的会话重启（看门狗）会在**同一工况内部**引入 ~0.1~1% 的网格差异；
   `b1_raw_runK.csv` 的 `aedt_pid` 列可用于识别（同一 `case_id` 内出现多个 pid 即发生过重启）。
