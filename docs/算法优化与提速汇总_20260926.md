## 3 当前生产口径的**适用性闸门**（关键保护机制）

几何越紧，柔性网格越危险。实测：

| 工况 | 匝间最小净间隙 | 柔性网格结果 |
|---|---|---|
| LC=200 / KR=0.25 | 4.38 mm | ✓ 有效（−12.6%，偏差 ≤0.33%） |
| LC=167.3 / KR=0.3587（参考点） | 2.56 mm | ✓ 有效 |
| LC=120 / KR=0.50 | **0.55 mm** | ❌ **Status='Error'**（26 个 body 表面网格被修坏，面积偏差 1~10%） |

```python
OPT_MIN_GAP = 1.5      # mm
gap_min = CG.path_dims(LC, KR)["gap_min"]
_use_opt = (gap_min is None) or (gap_min >= OPT_MIN_GAP)
# 不满足 -> 整套回退 BASE 口径：flex 关 + 无 ⑥ + pref 5 + rres 1e-06
```

**受影响的设计空间**：`gap = Lc·K_LC·(1−r_h)/24 − 2 < 1.5`，即 **小 Lc + 高 r_h** 那一角。

> ⚠️ **本批实测**：`gap_min < 1.5`（走 BASE）的工况共 **37 个**，其中 34 个顺利解出。
> **紧几何是必要不充分条件**——不要因为某工况走了 BASE 就预期它失败。

## 6 使用这些数字时的三个注意点

**① 单独百分比不能直接相乘。**
A1~A4 的单独收益（−39.6% / −9.8% / −22.4% / −4%）相乘得 **2.85×**，与组合实测 **2.85×** 一致；
但若与"叠在柔性上再 −25%"那几项**同时相加**会得 3.2× —— 那是**重复计入**（Region 粗化的收益
在"单独"和"叠加"两次测量里各算了一遍）。**引用时请用实测终值 4.78 min/点。**

**② 分批次的绝对值不同，比值才可比。**
| 文档 | 参考点单点 | 说明 |
|---|---|---|
| `4弦模板与提速验证_20260918.md` | **4.78 min** | 旧几何、旧空气域（±205/±330） |
| `batch规模与工期规划_20260919.md` | **7.10 min** | 新几何（独立双面铁氧体）+ 新空气域（±420）+ 8 实例并发争用 → **+49%** |

**③ 单次测量，噪声量级 ±3~5%。**
核数对比与部分提速项都是**每档只跑一次**；自适应网格本身带随机性（同点同设置网格规模可差 **10%**）。
要发表级别的加速比，需每档跑 3~5 次取中位数。
例：A3 的 pre15 与 pre10 之争（−9.7% vs −22.4%）就落在噪声敏感区，取 pre10 是**保守选择**而非精确最优。

## 7 一句话总结

**提速的三个来源（按贡献）**：优化网格组合 **2.85×** > 镜像半扫 **1.96×** > 多实例并行 **×3.9~8**；
**已经走到头的**：加核数、放宽收敛、GPU、MeshLink、全局粗化（后者还会静默产出错数据）；
**还剩的**：削减轮询固定开销（12~19 小时量级）、初始网格复用（每点 3 min）、降低网格器崩溃率。
