# 迁移包位置（面包屑文件）

若你在找这套 WPT 批量仿真的迁移包，它就在**本文件旁边**：

```
C:\ansys maxwell2024\_migration\pack\
```

## 直接可用的入口（按建议顺序读）

| 文件 | 用途 |
|---|---|
| `pack\交接说明_新设备.md` | **先读这个** —— 源机实测事实、冻结口径、全部教训 |
| `pack\迁移操作手册.md` | 主手册：9 节分阶段，每步含可执行命令与风险标注 |
| `新设备启动提示词.md` | 给新设备新会话的启动提示词（复制粘贴用） |
| `pack\tools\_site_config.example.json` | 站点配置模板 → 复制成 `_site_config.json` 后按新机实值填 |
| `pack\MANIFEST.json` | 245 个文件的 SHA256 清单 |
| `pack\新机启动前检查清单_b3.md` | 108 条逐项检查（在 `_migration\` 下） |

## 如果你在**新设备**上读到这里

说明你还没把包传过去。请先在源机把 `_migration\pack\` 整个目录（38.6 MB）
传到新设备，再在新设备上读 `pack\交接说明_新设备.md`。
**新设备上不存在 `C:\ansys maxwell2024` 这个目录**，不要试图访问它。
